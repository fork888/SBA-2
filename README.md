# Accessible Design Co.

## About This Project

I created this website for SBA 2. The website is for a fictional company called Accessible Design Co.

The goal of this project was to practice creating a responsive and accessible website using HTML and CSS. The website is designed to work on phones, tablets, and desktop computers while being easy for all users to navigate.

## Features

- Responsive navigation bar
- Responsive layout using CSS Grid
- Semantic HTML elements
- Accessibility features using ARIA attributes
- Contact form with labels
- Keyboard-friendly navigation
- Mobile, tablet, and desktop support

## Technologies Used

- HTML
- Style css
